Formas de conexión

Elegís cómo conectar WhatsApp. Podés cambiar cuando crezcas.

El CRM está pensado para empezar rápido y “formalizarse” después, sin migrar de sistema: la misma bandeja, las mismas conversaciones y las mismas integraciones.

Sin API oficial Disponible hoy

Vinculás el número escaneando un QR, como un WhatsApp Web, y empezás a atender en minutos.

  • Funciona con tu número y tu app actual
  • Sin plantillas ni aprobación previa
  • Sin costo por conversación de Meta
  • Protecciones anti-bloqueo integradas

Ideal para: empezar, validar y equipos chicos o medianos. Al no ser el canal oficial, tiene más riesgo de bloqueo que la API de Meta.

API oficial de Meta Próximamente

Conexión por la WhatsApp Business Platform (Cloud API), el canal oficial de Meta.

  • Canal homologado, el más estable a escala
  • Plantillas aprobadas para escribir primero
  • Números verificados y métricas de calidad
  • Pensado para alto volumen y campañas

Ideal para: empresas que escalan o necesitan cumplimiento formal. Requiere alta en Meta y tiene costo por conversación.

Coexistence Próximamente

Usás la API oficial y seguís con la app WhatsApp Business en el celular, sobre el mismo número.

  • Atención desde el CRM y desde el teléfono
  • Conserva el número y el historial de la app
  • Camino natural para pasar a lo oficial sin cortes

Ideal para: negocios que ya atienden con la app Business y quieren sumar equipo y automatización.

Para tu equipo

Una bandeja pensada para responder rápido y sin pisarse.

Multiagente

Varios operadores en el mismo número, con asignación manual o automática, estados de conversación y aviso de quién está viendo cada chat.

Notas internas por cliente

Anotá lo que el próximo operador debe saber. Las notas fijadas aparecen sobre el chat y el cliente nunca las ve.

Etiquetas y respuestas rápidas

Ordená consultas por tema y respondé en un toque con plantillas y una biblioteca de archivos (PDF, imágenes) lista para enviar.

Campañas con protección

Envíos masivos con personalización, variación de texto, baja automática (“STOP”) y límites que cuidan la reputación de tu número.

Anti-bloqueo

Cola de envío con intervalos naturales, topes distintos para contactos nuevos, horario silencioso, pausa automática ante señales de riesgo y lista de bloqueo.

Horarios y respuesta automática

Fuera de horario, un bot saluda y recoge nombre, email y motivo para que tu equipo retome al día siguiente.

Inteligencia artificial

La IA hace el trabajo repetitivo. Tu equipo, el que importa.

Elegís tu proveedor (OpenAI, Anthropic, Gemini o Groq) con tu propia API key. Cada función se activa por separado.

🎤 Transcripción de audios

Los audios entrantes se convierten en texto: se leen de un vistazo, se pueden buscar y la IA los entiende.

🗂 Clasificación automática

Detecta la intención, la prioridad y el estado de ánimo del cliente, y aplica tus etiquetas. Los casos urgentes o molestos se destacan en la bandeja.

👤 Asignación inteligente

Reparte conversaciones por carga de trabajo, por turnos o según la etiqueta, y deriva a una persona cuando el cliente la pide.

🧠 Base de conocimiento

Cargá notas día a día, archivos o pegá una URL: el sistema lee la página, la limpia y la guarda. La IA responde solo con lo que vos le cargaste, y no inventa.

Integraciones

Tu sistema avisa. WhatsApp entrega.

Una API simple para que tu tienda, tu plugin o tu ERP envíen mensajes cuando ocurre algo: una nueva orden, un pago, una reserva.

  • Plantillas con variables y destinatarios por evento (personas o grupos)
  • Cola persistente con reintentos y sin duplicados
  • Webhooks firmados cuando entra un mensaje
  • Claves de API por sistema, revocables en cualquier momento
# Nueva orden en tu tienda → aviso al equipo
curl -X POST https://tu-crm/api/v1/notify \
  -H "Authorization: Bearer wak_…" \
  -H "Idempotency-Key: order-1001" \
  -d '{
    "event": "new_order",
    "data": {
      "id": 1001,
      "customer": { "name": "Ana" },
      "total": "120.00 EUR"
    }
  }'

# → 202 Accepted: en cola, con reintentos

Cómo empezar

De cero a atender en una tarde.

Instalamos tu panel con tu marca, tu dominio y tus usuarios.

Conectás tu número. Hoy, escaneando un QR. Cuando lo necesites, pasás a la API oficial.

Cargás tu conocimiento (notas, archivos o una URL) y activás la IA que quieras.

Conectás tus sistemas con una API key y empezás a recibir avisos en WhatsApp.

Preguntas frecuentes

Lo que más nos preguntan

¿Necesito la API oficial de Meta para empezar?

No. Hoy podés conectar tu número con un QR, sin trámites. La API oficial y Coexistence están en camino para cuando necesites escalar o formalizar.

¿Me pueden bloquear el número?

En el modo sin API oficial existe ese riesgo, como con cualquier herramienta no oficial. Lo reducimos con límites de envío, pausas automáticas y baja de contactos, pero no se puede garantizar. Para volúmenes altos recomendamos la API oficial.

¿Puedo seguir usando WhatsApp en el celular?

Sí. En el modo QR el CRM funciona como un dispositivo vinculado. Con Coexistence (próximamente) también podrás usar la app Business sobre el mismo número.

¿Es marca blanca?

Sí. Podés ofrecerlo con tu nombre y tu dominio. Cada instalación es independiente.

¿Qué pasa con mis datos y mis API keys de IA?

El sistema se despliega en tu propio servidor y base de datos. Las claves de IA son tuyas y se usan solo para las funciones que actives.

¿Cuánto cuesta?

Escribinos y armamos una propuesta según el tamaño de tu equipo y la forma de conexión.
